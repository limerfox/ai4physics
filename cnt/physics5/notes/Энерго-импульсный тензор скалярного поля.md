# Энерго-импульсный тензор скалярного поля

T_μν = ∂_μφ ∂_νφ - ½ g_μν (∂_αφ ∂^αφ - m²φ² - ξ(Rφ² - 6(∇φ)²)) — тензор энергии-импульса для скалярного поля с неминимальной связью ξ.
