# Вывести выражение для скалярного поля на метрике де Ситтера

Запрос пользователя: «Выведи выражение для скалярного поля на метрике де Ситтера. Результат проверь предельным переходом.»

Готово, когда: файл `src/scalar_field_deSitter.py` содержит вывод выражения для скалярного поля и проверку предельным переходом H→0 к пространству Минковского; результат воспроизводим командой `python src/scalar_field_deSitter.py`

Не входит: квантование поля, вычисление энергии излучения, анализ инфракрасного поведения

## Итог

Все 3 подзадачи выполнены:
1. Выведено уравнение Клейна-Гордона (□ - m² - ξR)φ = J на де Ситтере
2. Получено решение φ(x) = q·G_dS(x,x₀) для точечного источника
3. Предельный переход H→0 проверен: метрика, даламбертиан, кривизна, уравнение — все переходят в соответствующие выражения Минковского

Файл: src/scalar_field_deSitter.py
Команда проверки: python src/scalar_field_deSitter.py
