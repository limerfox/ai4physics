## 2026-10-17 — Обновлённый эксперимент + полная верификация + новая статья

**Запрос:** Провести эксперимент, дать формальную верификацию, написать статью по шаблону ICML 2026, получить готовый PDF.

**Что сделано:**
1. Запущен Python-эксперимент `src/boyle_experiment.py` — 50 точек данных, V ∈ [1, 10] л, T = 300 K, n = 1.0 моль.
2. Результаты: pV = 2494.2 Дж (константа), максимальная относительная ошибка = 0%.
3. Сгенерированы 4 графика: P vs V, P vs 1/V, сохранение pV, анализ точности.
4. Написана Lean-верификация `src/boyle_lean.lean` — 7 теорем:
   - `boyle_symmetric` — симметрия P·V = V·P
   - `PV_conservation` — сохранение произведения
   - `inverse_proportionality` — обратная пропорциональность P₁/P₂ = V₂/V₁
   - `volume_doubles_pressure_halves` — удвоение объёма → половинное давление
   - `pressure_decreasing` — монотонность убывания
   - `numerical_verification` — численная проверка для n=1, T=300, V=5
   - `pressure_positive` — положительность давления
5. Все теоремы проверены через `lean_check` — все прошли успешно.
6. Написана статья `src/paper.tex` по шаблону ICML 2026 (7 секций, 8 рецензируемых источников).
7. Скомпилирован `paper.pdf` (4 страницы, 260 KB) через pdflatex + bibtex.

**Результат:** `paper/paper.pdf` — готовый PDF с расчётами, графиками и источниками.

**Способ проверки:**
- Повторный запуск: `python src/boyle_experiment.py`
- Lean-верификация: `lean_check` для `src/boyle_lean.lean`
- PDF: `paper/paper.pdf` (4 страницы, 260 KB)

**Способ проверки:**
- Повторный запуск: `python src/analyze_boyle.py` → `results/summary.json`
- Lean-верификация: `lean_check` для `src/boyle_verification.lean`
- PDF: `paper/paper.pdf` (5 страниц, %PDF-1.4)
