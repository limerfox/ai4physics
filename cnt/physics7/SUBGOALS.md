# Дерево под-целей: Конечное собственное время достижения горизонта в пространстве-времени Риндлера

## Шаблон

**Корень (что проверяем целиком):** в двумерном пространстве-времени Риндлера `ds^2 = -\rho^2 d\tau^2 + d\rho^2 (\rho>0)` времениподобная геодезическая с сохраняющийся энергией `E = \rho^2 \dot{\tau}` (где производная взята по собственному времени `s`) достигает горизонта `\rho = 0` за конечное собственное время `s_0 = E - \sqrt{E^2 - \rho_0^2}`, где `0 < \rho_0 \leq E` - начальный радиус. В то время как координатное время `\tau` до горизонта расходится логарифмически.

**Постановку проверил автор:** да, 2026-11-08. Сверено: сигнатура (-,+); `\rho>0`, `rho_0 \leq E`.
