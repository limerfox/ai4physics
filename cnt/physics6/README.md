# плоский предел точного решения массивного скалярного поля в пространстве-времени de Sitter -> Minkowski

## Физические соглашения

В проекте рассматривается свободное массивное скалярное поле с минимальной связью в четырехмерном пространстве-времени де Ситтера (в пространственно-плоском сечении):

\[ds^2=dt^2-e^{2Ht}d\mathbf{x}^2,\qquad a(t)=e^{Ht}.\]

Конформное время определяется как \(\eta=-e^{-Ht}/H\), при этом введены обозначения:

\[\nu=\sqrt{\frac94-\frac{m^2}{H^2}},\qquad z=-k\eta.\]

В файле `modes.py` используется выбор мод, соответствующий вакууму Банча-Дэвиса:

\[u_k(\eta)=\frac{\sqrt{\pi}}2 H(-\eta)^{3/2} e^{i\pi(\nu/2+1/4)}H_\nu^{(1)}(-k\eta).\]

Для сравнения приводится выражение для плоского пространства-времени Минковского:

\[u_k^{(M)}(t,\mathbf{x})=\frac{e^{-iE_kt+i\mathbf{k}\cdot\mathbf{x}}}{\sqrt{2E_k}}, \qquad E_k=\sqrt{k^2+m^2}.\]

Реализация предполагает, что `m > 0` и `k > 0`; используются единицы измерения, в которых `c = hbar = 1`.

## Методы

* `float64`: сравнение с низкой точностью; вычисления проводятся с использованием 17 десятичных знаков, после чего результат округляется до типа `complex` в Python (binary64). Поскольку стандартная функция для вычисления функций Ганкеля в библиотеке SciPy не поддерживает чисто мнимый порядок (который возникает при малых значениях $H$), данный метод выступает лишь в качестве аппроксимации, а не полноценной реализации функций Ганкеля в формате binary64.
* `mpmath`: то же самое выражение для функции Ганкеля, вычисленное с произвольной точностью.
* `asymptotic`: адиабатическое приближение (или приближение ВКБ) первого порядка по параметру $H$, полученное из разложения $\omega_H(t)=E_k-k^2tH/E_k+O(H^2)$. Это не является полным равномерным разложением Дебая для функции Ганкеля; данный метод включен исключительно как четко определенный асимптотический эталон для сравнения.

Глобальная фаза приведена к значению в точке `t_ref=0`; амплитуда не подвергается перенормировке. Это позволяет исключить фазовый сдвиг, не зависящий от координат, не маскируя при этом возможную погрешность в амплитуде.


## Запуск

Для пробного прогона:
```bash
python -m pip install -r requirements.txt
python run_experiment.py --output results --dps 60 --plan
python checks/check_plan.py --output results
```

Для короткой проверки после пробного прогона:
```bash
python checks/check_quick.py --output results
```

Для полного расчета после двух предыдущих шагов и проверки:
```bash
python run_experiment.py --output results --dps 60
python checks/check.py --output results
```

Полный цикл расчетов охватывает все комбинации 3 методов, 4 значений массы, 4 волновых чисел и 8 параметров Хаббла. Каждая серия, определяемая набором параметров `(метод, m, k)`, включает в себя расчеты для нескольких значений H.
Результаты:

* `results/runs.csv`: таблица со столбцами `(method, m, k, n_H, H_max, H_min, n_t, x, t_ref, dps, fit_last_n, run_id, run, H, max_relative_error, status, message)` и всеми результатами и параметрами, от которых зависели результаты.
* `results/summary.csv`: оценочный логарифмический наклон для каждого и rmse `(method, m, k, n_H, H_max, H_min, n_t, x, t_ref, dps, fit_last_n, run_id, run, p_estimate, log_fit_rmse, n_valid)`.
* `results/run_config.json`: полный набор конфигураций.
* `results/run_config.csv`: полный набор конфигураций.


## Важные замечания по интерпретации

По умолчанию аппроксимация для определения численного наклона выполняется только по последним четырем значениям $H$. Эта оценка носит диагностический характер и не является строгим доказательством асимптотического поведения. При этом точки, для которых слагаемых для сходимости результата не хватило, исключаются.

Ожидаемый порядок величины в пределе плоского пространства — $p=1$ (согласно теоретическим предсказаниям для произвольных фиксированных ненулевых моментов времени), при условии, что коэффициент при линейном члене не обращается в ноль. В некоторых особых точках (в частности, при $t=0$ в рамках WKB-приближения первого порядка) ведущий коэффициент может зануляться, из-за чего наблюдаемый порядок может оказаться выше.
