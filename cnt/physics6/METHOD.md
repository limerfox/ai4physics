# Методика проверки: <плоский предел точного решения массивного скалярного поля в пространстве-времени де Ситтера>

## 0. Паспорт

| Поле | Значение |
|---|---|
| Задача | численная проверка перехода точного решения свободного массивного скалярного поля в пространстве-времени де Ситтера к решению в пространстве-времени Минковского при (H \to 0) |
| Дисциплина | теоретическая физика |
| Ветка верификатора | модель с известным ответом |
| Дата записи методики | 2026-11-01 |
| Метка git | `exp-ds-mink-baseline` |

## 1. Замысел

- **Вопрос:** насколько точно точное решение свободного массивного скалярного поля в пространстве-времени де Ситтера воспроизводит соответствующее решение в пространстве-времени Минковского при стремлении кривизны к нулю?
- **Гипотеза:** при (H \to 0) решение в пространстве-времени де Ситтера стремится к соответствующему решению в пространстве-времени Минковского. Ошибка должна стремиться к нулю с предсказуемым порядком сходимости (p = 1).
- **Что считается ответом:** зависимость ошибки от (H), оценённый порядок сходимости и сравнение точности трёх методов вычисления решения.


## 2. Постановка

| Что | Значение |
|---|---|
| Что меняем (факторы и уровни) | метод вычисления: float64 / повышенная точность mpmath / асимптотическое приближение; (H): несколько значений от (10^{-1}) до (3*10^{-5}); масса (m): 4 значения; волновой номер (k): 4 значения |
| Что фиксируем | тип поля — свободное массивное скалярное поле; состояние — Bunch–Davies; координатную систему; набор точек (t,x), в которых производится сравнение |
| Что измеряем, в каких единицах | безразмерная относительная ошибка между решением de Sitter и решением Минковского; оценка порядка сходимости (p) из (\epsilon(H) \sim H^p), выполняется по последним 4 точкам из прогона (то есть, при H = (1e-3, 3e-4, 1e-4, 3e-5)) |
| Базовая линия | аналитическое решение свободного массивного скалярного поля в пространстве-времени Минковского |

Для каждой конфигурации вычисляется решение де Ситтера [\phi_{dS}(H,m,k,t,x)] и соответствующее решение Минковского [\frac{e^{-iE_k t+ikx}}{\sqrt{2E_k}}, \qquad E_k=\sqrt{k^2+m^2}]. Перед сравнением удаляется общая (H)-зависимая фаза, не зависящая от координат.

## 4. Код и окружение

- Где код: `src/limit/` — вычисление точных решений и функций ошибок, две таблицы с результатами (короткая "summary.csv" --- одна строка на серию (method, m, k), длинная "runs.csv" --- одна строка на пару (конфигурация, H)).
- Команда запуска: скрипт run_experiment.py `python run_experiment.py --output results --dps 80`, где `results` --- папка, где будут лежать планы прогонов, таблицы результатов, `dps` --- точность вычисления в методе `mpmath` (в методе `float64` она фиксированно равна 17); в конец можно добавить флаги `--plan` --- скрипт совершит пробный прогон и подготовит все конфигурации для эксперимента, без флага будет совершен полный расчет. Для корректной отработки надо действовать по шагам глубины: сначала запустить пробный прогон и проверку, потом короткую проверку, потом полный расчет и проверку для него.
- Окружение: Python 3.11, пакеты из `requirements.txt`.
- Значения seed: случайность отсутствует.

## 5. Верификатор

- **Что проверяет:** сходимость решения de Sitter к решению Минковского, порядок сходимости, воспроизводимость вычислений. 
- **Команда:**
    `python checks/check_plan.py --output results` --- запуск проверки пробного прогона,
    `python checks/check_quick.py --output results` --- запуск короткой проверки,
    `python checks/check.py --output results` --- запуск проверки после полного расчета.
- **Где лежит:** `checks/`, закрыт от записи для агента.
- **Чего не проверяет:** что исходное выражение для решения де Ситтера действительно является решением уравнения Клейна–Гордона; физическую корректность выбора вакуумного состояния; вывод аналитического выражения для асимптотики функции Ганкеля.

## 7. Правило принятия (записано до запуска)

1. **Метрика и единицы:** относительная безразмерная ошибка между решениями после удаления общей (H)-зависимой фазы: [\epsilon(H)=\left|\frac{\phi_{dS}(H)}{\phi_M}-1\right|].
2. **Повторы:** вычисления детерминированы; повторный запуск одной конфигурации должен давать тот же результат с точностью до численного допуска.
3. **Сравнение:** для каждого метода вычисляется (p) из зависимости [\log\epsilon = p\log H+C] и сравнивается с теоретическим значением (p=1) с погрешностью \pm 0.2.
4. **Практический порог:** невозможно предварительно оценить, поскольку неизвестна вычислительная ошибка каждого метода.
5. **Выбор варианта:** метод считается более точным, если при одинаковых входных параметрах он даёт меньшую ошибку, коэффициент (p) метода даёт значение ближе к истинному, сохраняет устойчивость при уменьшении (H). Выбор производится по всем значениям (H).
6. **Разбиение для вывода:** метод считается прошедшим проверку, если ошибка стремится к нулю при (H \to 0), а измеренный порядок сходимости согласуется с аналитическим предсказанием с точностью до погрешности. Если метод не позволяет исследовать достаточно малые (H) из-за потери точности, это фиксируется как ограничение метода, а не как опровержение физического предела.
