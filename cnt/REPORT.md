## 2. Методика

Задача: с помощью трех разных вычислительных методов определить, насколько точно точное решение свободного массивного скалярного поля в пространстве-времени де Ситтера воспроизводит соответствующее решение в пространстве-времени Минковского при стремлении кривизны к нулю. Ошибка должна стремиться к нулю с предсказуемым порядком сходимости (p = 1). Меняются: метод вычисления: float64 / повышенная точность mpmath / асимптотическое приближение; (H): несколько значений от (10^{-1}) до (3*10^{-5}); масса (m): 4 значения; волновой номер (k): 4 значения; фиксируем: тип поля — свободное массивное скалярное поле; состояние — Bunch–Davies; координатную систему; набор точек (t,x), в которых производится сравнение; вычисления детерминированы; правила принятия — повторный запуск одной конфигурации должен давать тот же результат с точностью до численного допуска, для каждого метода вычисляется (p) из зависимости [\log\epsilon = p\log H+C] и сравнивается с теоретическим значением (p=1) с погрешностью \pm 0.2.

## 3. Верификатор

- **Что проверяет:** сходимость решения de Sitter к решению Минковского, порядок сходимости, воспроизводимость вычислений. 
- **Как устроен:** проверяет результаты (ошибку и порядок сходимости) с пмощью трех функций: `test_error_monotonically_decrease` (монотонное убывание модуля ошибки с уменьшением кривизны (с точностью до численного допуска)), `test_convergence_order`(оцененнный порядок сходимости (p) равен 1 (с погрешностью \pm 0.2)), `test_deterministic_result` (одинаковая конфигурация даёт одинаковый результат)
- **Команда:**
    `python checks/check_plan.py --output results` --- запуск проверки пробного прогона,
    `python checks/check_quick.py --output results` --- запуск короткой проверки,
    `python checks/check.py --output results` --- запуск проверки после полного расчета.
- **Где лежит:** `checks/`, закрыт от записи для агента.
- **Чего не проверяет:** что исходное выражение для решения де Ситтера действительно является решением уравнения Клейна–Гордона; физическую корректность выбора вакуумного состояния; вывод аналитического выражения для асимптотики функции Ганкеля.

Численная схема — задача с известным решением, ожидаемый порядок, шаги, интервал
принятия.
