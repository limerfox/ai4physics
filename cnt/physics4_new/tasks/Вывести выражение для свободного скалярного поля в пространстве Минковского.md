## Итог

Получено выражение для свободного скалярного поля в пространстве Минковского:

1. Метрика: $ds^2 = -dt^2 + dx^2 + dy^2 + dz^2$
2. Уравнение Клейна-Гордона: $(\Box + m^2)\phi = 0$
3. Разложение по плоским волнам:
   $$\phi(t,\mathbf{x}) = \int \frac{d^3k}{(2\pi)^3}\,\frac{1}{\sqrt{2\omega_{\mathbf{k}}}}\left[a_{\mathbf{k}}\,e^{-i\omega_{\mathbf{k}}t + i\mathbf{k}\cdot\mathbf{x}} + a_{\mathbf{k}}^\dagger\,e^{+i\omega_{\mathbf{k}}t - i\mathbf{k}\cdot\mathbf{x}}\right]$$
   где $\omega_{\mathbf{k}} = \sqrt{\mathbf{k}^2 + m^2}$
4. Нормировка мод через скалярное произведение Клейна-Гордона
5. Лагранжиан и тензор энергии-импульса
