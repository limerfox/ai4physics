# Проверить предельный переход H→0 к плоскому пространству Минковского

Готово, когда: заметка notes/proverka_predel_perexodom.md с явным выводом, что при H→0 решение переходит в плосковолновое решение уравнения Клейна-Гордона в Минковском

## Итог

Проверен предельный переход H→0:

1. Уравнение для моды на де Ситтере:
   u_k'' + 3H u_k' + (k²e^(-2Ht) + m² + 12ξH²)u_k = 0

2. При H→0:
   - 3H·u̇_k → 0
   - k²e^(-2Ht) → k²
   - 12ξH² → 0

3. Уравнение переходит в:
   u_k'' + (k² + m²)u_k = 0

4. Решение:
   u_k(t) = (1/√(2ω_k)) e^(-iω_k t), ω_k = √(k² + m²)

5. Полное поле:
   φ(t,x) = ∫d³k [a_k (1/√(2ω_k)) e^(-iω_k t + ik·x) + c.c.]

Это — стандартное разложение свободного скалярного поля в пространстве Минковского.

Также проверен конформный случай (ξ=1/6, m=0):
   φ_k = -Hη/√(2k) e^(-ikη) → (1/√(2k)) e^(-ikt) при H→0.
