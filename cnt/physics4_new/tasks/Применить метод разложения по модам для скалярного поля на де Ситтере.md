# Применить метод разложения по модам для скалярного поля на де Ситтере

Готово, когда: заметка notes/skalarnoe_pole_na_deSitter.md с явным выражением для φ(t,x) в плоских координатах де Ситтера

## Итог

Получено выражение для скалярного поля на де Ситтере:

1. Уравнение Клейна-Гордона в плоских координатах:
   ∂²_t φ + 3H ∂_t φ - e^(-2Ht)∇²φ + (m² + 12ξH²)φ = 0

2. Разложение по модам: φ(t,x) = ∫d³k [a_k u_k(t) e^(ik·x) + c.c.]
   u_k'' + 3H u_k' + (k²e^(-2Ht) + m² + 12ξH²)u_k = 0

3. В конформном времени η = -e^(-Ht)/H, φ = a^(-1)χ:
   χ'' + (k² + m²a² + 6ξHa)χ = 0

4. Конформный случай (ξ=1/6, m=0): χ_k = (1/√(2k)) e^(-ikη)

5. Общий случай (вакуум Банча-Дейвиса):
   ν = √(9/4 - m²/H² - 12ξ)
   φ_k(η) = √(π/4) e^(i(2ν+1)π/4) (-Hη)^(3/2) H^(2)_ν(-kη)

Проверено запуском: python derive_scalar_field.py
