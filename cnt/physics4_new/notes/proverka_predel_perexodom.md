# Предельный переход H→0 к пространству Минковского

Проверка: при H→0 решение уравнения Клейна-Гордона на де Ситтере переходит в стандартное разложение свободного скалярного поля в пространстве Минковского.

## Вывод

### Уравнение для моды на де Ситтере

В плоских координатах де Ситтера:
- ds² = -dt² + e^(2Ht)(dx² + dy² + dz²)
- a(t) = e^(Ht)

Уравнение Клейна-Гордона:
$$\Box\phi - (m^2 + \xi R)\phi = 0$$

где R = 12H² — скаляр Риччи де Ситтера.

Даламбиан в этих координатах:
$$\Box\phi = -\partial_t^2\phi - 3H\partial_t\phi + e^{-2Ht}\nabla^2\phi$$

Уравнение для моды u_k(t) при разложении φ(t,x) = ∫d³k a_k u_k(t) e^(ik·x):
$$\ddot{u}_k + 3H\dot{u}_k + (k^2 e^{-2Ht} + m^2 + 12\xi H^2)u_k = 0$$

### Предельный переход H→0

При H→0:
- 3H·u̇_k → 0
- k²e^(-2Ht) → k²
- 12ξH² → 0

Уравнение переходит в:
$$\ddot{u}_k + (k^2 + m^2)u_k = 0$$

Решение:
$$u_k(t) = \frac{1}{\sqrt{2\omega_k}} e^{-i\omega_k t}, \quad \omega_k = \sqrt{k^2 + m^2}$$

Полное поле:
$$\phi(t,\mathbf{x}) = \int \frac{d^3k}{(2\pi)^3} \frac{1}{\sqrt{2\omega_k}} \left[a_{\mathbf{k}} e^{-i\omega_k t + i\mathbf{k}\cdot\mathbf{x}} + a_{\mathbf{k}}^\dagger e^{i\omega_k t - i\mathbf{k}\cdot\mathbf{x}}\right]$$

Это — стандартное разложение свободного скалярного поля в пространстве Минковского.

### Конформный случай (ξ = 1/6, m = 0)

При ξ = 1/6, m = 0 поле конформно инвариантно. В конформном времени η = -e^(-Ht)/H:
- a(η) = -1/(Hη)
- ds² = a²(η)(-dη² + d**x²)

Уравнение для χ = aφ: χ'' + k²χ = 0
Решение: χ_k = (1/√(2k)) e^(-ikη)
φ_k = a^(-1)χ_k = -Hη/√(2k) e^(-ikη)

При H→0: a → 1, η → t (с точностью до константы)
φ_k → (1/√(2k)) e^(-ikt) — плосковолновая мода Минковского.
