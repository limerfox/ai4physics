# Отчёт: скалярное поле на метрике де Ситтера и предельный переход H→0

## Цель

Вывести выражение для скалярного поля на фоне де Ситтера в плоских координатах и проверить предельный переход H→0 к пространству Минковского.

## Результаты

### 1. Уравнение Клейна-Гордона в плоских координатах де Ситтера

Метрика: ds² = -dt² + e^(2Ht)(dx² + dy² + dz²)

Даламбиан:
$$\Box\phi = -\partial_t^2\phi - 3H\partial_t\phi + e^{-2Ht}\nabla^2\phi$$

Уравнение Клейна-Гордона:
$$\partial_t^2\phi + 3H\partial_t\phi - e^{-2Ht}\nabla^2\phi + (m^2 + 12\xi H^2)\phi = 0$$

### 2. Разложение по модам

$$\phi(t,\mathbf{x}) = \int d^3k \left[a_{\mathbf{k}} u_{\mathbf{k}}(t) e^{i\mathbf{k}\cdot\mathbf{x}} + \text{c.c.}\right]$$

Уравнение для моды:
$$\ddot{u}_{\mathbf{k}} + 3H\dot{u}_{\mathbf{k}} + (k^2 e^{-2Ht} + m^2 + 12\xi H^2)u_{\mathbf{k}} = 0$$

### 3. Конформное время и поле

Конформное время: η = -e^(-Ht)/H, a(η) = -1/(Hη)

Переход φ = a^(-1)χ:
$$\chi'' + (k^2 + m^2 a^2 + 6\xi Ha)\chi = 0$$

**Конформный случай** (ξ = 1/6, m = 0):
$$\chi_k = \frac{1}{\sqrt{2k}} e^{-ik\eta}, \quad \phi_k = -\frac{H\eta}{\sqrt{2k}} e^{-ik\eta}$$

**Общий случай** (вакуум Банча-Дейвиса):
$$\nu = \sqrt{\frac{9}{4} - \frac{m^2}{H^2} - 12\xi}$$
$$\phi_k(\eta) = \frac{\sqrt{\pi}}{2} e^{i(2\nu+1)\pi/4} (-H\eta)^{3/2} H_\nu^{(2)}(-k\eta)$$

### 4. Предельный переход H→0

При H→0 уравнение для моды переходит в:
$$\ddot{u}_{\mathbf{k}} + (k^2 + m^2)u_{\mathbf{k}} = 0$$

Решение:
$$u_{\mathbf{k}}(t) = \frac{1}{\sqrt{2\omega_{\mathbf{k}}}} e^{-i\omega_{\mathbf{k}} t}, \quad \omega_{\mathbf{k}} = \sqrt{k^2 + m^2}$$

Полное поле в Минковском пространстве:
$$\phi(t,\mathbf{x}) = \int \frac{d^3k}{(2\pi)^3} \frac{1}{\sqrt{2\omega_{\mathbf{k}}}} \left[a_{\mathbf{k}} e^{-i\omega_{\mathbf{k}} t + i\mathbf{k}\cdot\mathbf{x}} + a_{\mathbf{k}}^\dagger e^{i\omega_{\mathbf{k}} t - i\mathbf{k}\cdot\mathbf{x}}\right]$$

Конформный случай: φ_k → (1/√(2k)) e^(-ikt) — плосковолновая мода Минковского.
