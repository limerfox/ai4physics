# Скалярная волна от свободной частицы

Свободная скалярная частица с зарядом g, движущаяся по мировой линии z(τ), создаёт скалярное поле φ, удовлетворяющее уравнению Клейна-Гордона с источником. Излучение характеризуется потоком энергии через бесконечно удалённую поверхность.
