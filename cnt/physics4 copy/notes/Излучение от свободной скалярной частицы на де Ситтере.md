# Излучение от свободной скалярной частицы на де Ситтере

Свободная скалярная частица с зарядом g, движущаяся по геодезической z(τ), создаёт поле φ, удовлетворяющее (□ - m² - ξR)φ = J. Мощность излучения: P = ∮ dΩ · lim_{r→∞}[e^(Ht)·r²·∂_tφ∂_rφ]. Для лёгких полей (m² + ξR < 5H²/4): P ≠ 0. При H→0: P→0.
