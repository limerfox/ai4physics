# Пространство-время Риндлера

Плоское пространство-время Минковского, описанное в ускоряющихся координатах. Метрика: $ds^2 = \rho^2 d\eta^2 - d\rho^2 - dy^2 - dz^2$. Охватывает только часть глобального пространства Минковского (Rindler wedge).
