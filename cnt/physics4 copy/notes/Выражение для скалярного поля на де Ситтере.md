# Выражение для скалярного поля на де Ситтере

Уравнение Клейна-Гордона: (□ - m² - ξR)φ = J
Даламбертиан: □φ = ∂_t²φ + 3H·∂_tφ - exp(-2Ht)·∇²φ
Кривизна: R = 12H²
Решение: φ(x) = q·G_dS(x,x₀) для точечного источника.
Предельный переход H→0: □ → ∂_t² - ∇², R → 0, G_dS → G_Mink.
