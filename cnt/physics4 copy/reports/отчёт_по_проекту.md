# Отчёт по проекту: излучение полей в криволинейном пространстве-времени

## 1. Цель исследования

Исследовать излучение от различных полей в искривлённом пространстве-времени — в частности, вывести аналитические выражения для скалярного поля и его излучения в пространствах де Ситтера и Риндлера, проверить предельные переходы к пространству Минковского.

## 2. Выполненные задачи

### 2.1. Скалярное поле на метрике де Ситтера

**Задача:** [[Вывести выражение для скалярного поля на метрике де Ситтера]]

Подзадачи:
1. [[Вывести уравнение Клейна-Гордона для скалярного поля на де Ситтере]] — выведено уравнение (□ − m² − ξR)φ = J в плоских координатах де Ситтера, где □φ = ∂_t²φ + 3H·∂_tφ − exp(−2Ht)·∇²φ, R = 12H².
2. [[Решить уравнение Клейна-Гордона с точечным источником]] — получено решение φ(x) = q · G_dS(x, x₀) через функцию Грина, источник J(x) = q·δ⁴(x−x₀)/√(−g).
3. [[Проверить предельным переходом H→0 к пространству Минковского]] — проверены 4 перехода: метрика → η_μν, □ → ∂_t² − ∇², R → 0, уравнение → (□_Mink − m²)φ = J.

**Файл:** [[src/scalar_field_deSitter.py]]

### 2.2. Излучение от скалярной свободной частицы на де Ситтере

**Задача:** [[Вывести излучение от скалярной свободной частицы на де Ситтере]]

Подзадачи:
1. [[Вывести ток свободной скалярной частицы]] — выведен ток J(x) = g ∫ dτ δ⁴(x − z(τ)) / √(−g) для мировой линии z^μ(τ) = (τ, 0, 0, 0) — геодезической.
2. [[Вывести мощность излучения скалярной волны]] — выведено выражение P = ∮ dΩ · lim_{r→∞}[e^(Ht)·r²·∂_tφ∂_rφ]. Для лёгких полей (m² + ξR < 5H²/4) P ≠ 0.
3. [[Проверить излучение предельным переходом H→0]] — проверено: □ → ∂_t² − ∇², R → 0, P → 0 (в Минковском свободная частица не излучает).

**Файл:** [[src/scalar_radiation_deSitter.py]]

### 2.3. Излучение от скалярной свободной частицы в пространстве-времени Риндлера

**Задача:** [[Вывести излучение от скалярной свободной частицы в пространстве-времени Риндлера]]

Подзадачи:
1. [[Вывести метрику Риндлера и уравнение КГ]] — выведена метрика ds² = ρ²dη² − dρ² − dy² − dz² и уравнение КГ.
2. [[Вывести ток и решение для поля]] — выведен ток J = g·δ(ρ−ρ₀)·δ(y)·δ(z)/ρ₀ и решение для статического поля.
3. [[Вывести мощность излучения и проверить предел]] — выведено P_Rindler = 0 (поле статично) и проверен предел к Минковскому, где P_Mink > 0 (равноускоренная частица излучает).

**Файл:** [[src/scalar_radiation_Rindler.py]]

## 3. Ключевые результаты

| Фон | Поле | Метод | Результат |
