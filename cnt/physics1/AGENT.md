# AGENT.md — <название проекта>

Файл-договор с агентом. Агент читает его в начале каждой сессии.
Тот же договор у других агентов называется `AGENTS.md`, `CLAUDE.md`, `.cursorrules`.

## Цель проекта
Получить уравнение движения для свободного скалярного поля в произвольном пространстве-времени.
Решить это уравнение в Expanding Poincare patch (с конформным временем) в de Sitter пространстве-времени.
Исследовать асимптотики решения.

## Данные и материалы
- Исходные данные не изменять; производные файлы — в `results/`.

## Как работать
- Расчёты — скриптами Python в `src/`, запускать перед тем, как сообщать результат.
- Каждый вывод сопровождается способом его проверки.
- Сводки и заметки для следующих сессий — в `memory/`.

## Журнал
- После каждой задачи — запись в `diary.md`: дата, запрос, что сделано,
  результат, точка проверки, итог проверки. Старые записи не менять.

## Запрещено
- Удалять или перезаписывать файлы в `data/`.
- Читать и выводить содержимое `.env` и других файлов с ключами.
- Выполнять `git push`, `rm -rf`, `sudo` без подтверждения.
