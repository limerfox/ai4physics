# План статьи: Излучение скалярного поля от волны в пространстве-времени Риндлера

## Введение
- Постановка задачи: вывод выражения для излучения скалярного поля, источником которого является скалярная волна
- Связь с известным результатом для точечной частицы (из paper.pdf)
- Ключевой вопрос: при локализации волнового источника он должен переходить в точечный

## 1. Скалярное поле и уравнение движения
### 1.1 Уравнение Клейна-Гордона с источником
- $\square \phi = J$ в пространстве-времени Риндлера
- Метрика: $ds^2 = \rho^2 d\tau^2 - d\rho^2 - dy^2 - dz^2$
- Ретардированный Грин и решение через интеграл по мировой линии

### 1.2 Ток от точечной частицы
- $J(x) = q \int d\theta \, \delta^{(4)}(x - z(\theta))$
- Мировая линия: ускорение по $x$, постоянное движение по $y$
- Решение для поля и поток энергии

### 1.3 Ток от скалярной волны
- $J(x) = f(x)$ — распределённый источник
- Волновая функция как источник: $f(x) = \psi_{\text{wave}}(x)$
- Предел локализации: $f(x) \to q \delta^{(4)}(x - z(\theta))$

## 2. Излучение от точечной частицы в пространстве-времени Риндлера
### 2.1 Ретардированное решение
- Связь между ретардированным временем и координатами наблюдения
- Функция $f(\tau, \rho, y, z, \theta)$ из оригинальной статьи

### 2.2 Поток энергии
- Энерго-импульсный тензор скалярного поля: $T_{\mu\nu} = \partial_\mu \phi \partial_\nu \phi - \frac{1}{2} g_{\mu\nu} (\partial^\alpha \phi \partial_\alpha \phi)$
- Вектор Пойнтинга и поток через бесконечно удалённую поверхность
- Сравнение со статическим случаем $\varphi = 0$

## 3. Излучение от скалярной волны
### 3.1 Волновой источник
- Конкретный вид волновой функции: $\psi_{\text{wave}}(x) = A(x) e^{i S(x)}$
- Ток: $J(x) = \psi_{\text{wave}}(x)$ или $J(x) = |\psi_{\text{wave}}(x)|^2$
- Физическая интерпретация

### 3.2 Решение и поток энергии
- Интеграл по пространству-времени с Грин-функцией
- Асимптотика на бесконечности
- Выражение для $dI/d\Omega$

### 3.3 Переход к точечной частице
- Предел: волновая функция сужается до мировой линии
- Совпадение токов: $J_{\text{wave}} \to J_{\text{particle}}$
- Совпадение потоков энергии

## 4. Выводы
- Получено выражение для излучения от скалярной волны
- В пределе локализации результат совпадает с излучением от точечной частицы
- Интерпретация: волна как распределённый источник излучения в Риндлеровском пространстве
