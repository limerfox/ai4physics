# AGENTS.md — излучение от разных источников

## 0. Цель и образ результата

На основе статьи получить выражение для излучения волны скалярного поля, источником которого является скалярная волна, в пространстве-времени Риндлера.

В конце работы в проекте существуют:
- `results/new_paper.pdf` - статья с выводом формул;
- запись в `diary.md` о прогоне с командой проверки и её кодом.

Ничего больше создавать не надо.

## 1. Критерий готовности

```
python -m pytest tests/ -q
```

Команда завершается с кодом 0. Вызови проверку сам перед тем, как дать окончательный ответ.

## 2. Карта проекта и источники
Где что лежит — в `INDEX.md`. Прочитай его первым и открывай только нужные файлы по ссылкам оттуда. Сжатие основной статьи проекта — `memory/L2.md`.

### Чего агент не может знать сам

- В статье paper.pdf как источник электромагнитного излучения рассматривается точечный ускоряющийся заряд, что напрямую не связано с целью дальнейшей работы.
- До вывода выражения для излучения от волны необходимо исследовать излучение от скалярной частицы, движущейся по мировой линии, в пространстве-времени Риндлера.

`paper/` — pdf статья, только чтение.
`diary.md` — журнал проекта; только дописывается.
`tests/` — проверка наличия нужного файла.

## 3. Инструменты и границы
- Python 3.10+, numpy, pytest, latex. Новые зависимости не устанавливать.
- Команды запускаются из корня проекта: `python -m pytest tests/ -q`.
- Сеть и Lean не нужны: `AI4SCIENCE_WEB_DISABLED=1 ai4science --no-lean`.
